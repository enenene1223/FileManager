# V0.3 核心操作测试

测试文件：`tests/core_copy_move_test.cpp`

## 覆盖内容

- 普通文件复制
- 文件夹递归复制
- 复制后的节点独立性
- 复制时间属性规则
  - `created_time` 使用复制时刻
  - `modified_time` 继承源节点
- 文件移动
- 文件夹移动
- 移动后路径更新
- 禁止移动到自身/子目录
- 禁止复制到自身/子目录
- 回收站后的递归永久删除

## 独立编译

在项目根目录执行：

```bash
g++ -std=c++17 -Wall -Wextra -pedantic \
    tests/core_copy_move_test.cpp \
    FileNode.cpp FileSystem.cpp \
    -o core_copy_move_test

./core_copy_move_test
```

Windows + MinGW 下也可以直接用同样的 `g++` 命令；若终端没有识别 `g++`，使用 Qt 安装目录中的 MinGW `bin` 目录对应的编译器，或在 Qt Creator/VS Code 中配置同一套 Kit。

通过时应输出：

```text
[PASS] copy/move/recursive core operations
```
