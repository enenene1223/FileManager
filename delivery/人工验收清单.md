# 人工验收清单（以下项目尚需现场手测）

自动回归和离屏界面测试不能替代真实鼠标、显示器、登录主循环和现场网络检查。请在最终解压目录上勾选，不要把未勾选项视为通过。

## 开始前

- [ ] 备份现有 users.txt 和 data_*.txt，使用独立演示目录；确认不是旧版进程。
- [ ] 关闭 Qt Creator 后，双击启动脚本仍能打开；若有另一台 Windows 64 位电脑，整体复制后试跑一次。
- [ ] 注册两个新的演示账号；检查重复账号、错误密码、正确登录和空输入提示。
- [ ] 记下隐私密码；若已有加密存档，不在现场演示直接修改隐私密码。

## 文件操作与存档

- [ ] 新建目录及多个 TXT，输入中文、英文、换行正文并保存。
- [ ] 重命名时图标保留、后缀不自动选中；非法名称及同名拒绝没有误覆盖。
- [ ] 复制/粘贴文件与多级目录，修改副本确认原件不变；剪切后移动到其他目录。
- [ ] 删除进回收站、恢复原位置；制造重名后恢复被拒绝；撤销新建、重命名、移动、删除。
- [ ] 清空回收站与永久删除仅针对准备好的演示对象；取消确认时数据不变。
- [ ] 退出重启后正文、目录、固定项正常；账号 A 注销后出现登录页，账号 B 登录看不到 A 的文件；再切回 A 检查。

## 隐私与异常

- [ ] 首次锁定要求验证，隐藏隐私后列表、搜索和归类均不泄露受保护内容。
- [ ] 错误隐私密码不能解锁，正确密码能恢复正文；锁定后退出重启仍可用原密码解密。
- [ ] 隐私文件总览不显示「自动归类」；双击只用于定位，普通目录中的归类仍可用。
- [ ] 仅在备份副本上测试损坏存档，确认提示保护且未自动覆盖；用可信备份恢复后重开。不要损坏唯一原件。
- [ ] 若目录不可写、磁盘空间不足或退出保存失败，核对错误提示和取消退出行为。自动测试没有模拟所有磁盘故障。

## 搜索、归类和摘要

- [ ] 普通搜索名称优先；开关正文搜索，验证中英文已支持词组，例如 游戏 / games。
- [ ] 搜索框为空时仅选日期、类型、大小仍生效；测试无结果、范围、排序、双击定位及路径栏前进后退。
- [ ] 本地自动归类能选候选，取消不移动，确认后能撤销；无选择时显示会话历史。
- [ ] 用自己的 Key 测试 AI 连接；查看错误认证、断网或取消后的提示，本地功能继续可用。
- [ ] 创建时间有先后的两份点名册，AI 搜索选出较新文件并给出依据；检查同秒并列时没有错误声称唯一最新。
- [ ] AI 搜索任务不进入普通搜索框；将结果显示到文件列表后双击可定位。
- [ ] AI 归类可选多个带理由的候选；选择非第一项确认移动，再撤销。
- [ ] TXT 摘要可读、文件名和覆盖范围正确，复制到记事本内容完整；空文件不发送请求，加密文件禁止上传。
- [ ] 长文本摘要明确提示仅处理前12000字符；检查模型没有编造日期、姓名、人数或待办。

## 显示与交付

- [ ] 100% / 125% / 150% 缩放、最大化、还原、最小窗口下标题、按钮、列和弹窗不挤压；下拉菜单长文字可读。
- [ ] 深目录、长中文名、侧栏展开、列表滚动、空白取消选择、右键菜单、快捷键和弹窗焦点符合预期。
- [ ] 演示至少准备一条离线路径；在线 AI 失效时不临时更改源码或密钥配置逻辑。
- [ ] 提交干净 ZIP、校验值和对应 Git 标签；不要重新压缩含自己数据、账号或个人配置的演示目录。

结论：人工验收人员、时间、设备、通过项和未通过项由实际操作者补充；此清单生成时未宣称以上操作全部完成。
