# FileManager 验收版使用说明

验收时间：2026 年 10 月 16 日 08:00（北京时间）。

## 启动

1. 将 ZIP 整体解压到本地可写目录，例如桌面或 D 盘。不要在压缩包内运行，不要只复制 EXE，不要放入需要管理员权限的 Program Files。
2. 双击「启动 FileManager.cmd」。必须保留 EXE 同目录的 DLL、platforms、tls 等子目录。
3. 首次运行没有预置账号，点击「注册」创建演示账号。记住登录密码和隐私密码。
4. 普通使用不需要安装 Qt、MinGW、OpenSSL 或 MSYS2。包内已经包含运行库；目标是 64 位 Windows 桌面环境。

## 数据与备份

这是应用内部的虚拟文件系统，不是 Windows 磁盘文件浏览器。创建、删除、归类等操作针对项目管理的文件对象。

启动脚本将工作目录设为程序目录。首次注册、保存后，会在此处生成 users.txt 和 data_账号.txt；发布包不含任何预置账号或个人存档。

升级前先退出程序，将原运行目录的 users.txt 和所有 data_*.txt 复制到独立备份目录。确认备份后，把需要保留的账号文件和对应存档复制到新版本运行目录；不要覆盖仅存的一份备份。已损坏的存档会阻止自动保存，请先备份并恢复可信副本。

不要同时打开多个实例修改同一账号存档。保留隐私密码；已有加密记录时，本版禁止通过登录页直接更换隐私密码，避免旧密文无法解开。

## 三项演示功能

- 本地搜索：名称优先、可选 TXT 正文，支持内置中英文同义词、范围、修改日期、类型、大小、排序及双击定位；不联网。
- DeepSeek 辅助 / 智能搜索：AI 调用只读工具查看未加密文件的名称和属性、比较时间，再给出选中结果及依据。点击「在文件列表中显示结果」后可双击定位。搜索任务不写入普通搜索框。
- 自动归类：本地规则可直接给候选位置；AI 归类最多给三个带理由的候选，选择后明确确认移动，支持主窗口撤销。取消不移动。
- TXT 摘要：先选文件，再进入生成摘要模式；保留上传确认。显示概括、主要内容、关键词以及全文/部分覆盖说明，成功后可复制，不覆盖原文件。

## AI 配置

AI 是可选功能。无密钥、断网或服务失败时，本地文件管理、搜索和归类仍可使用。

在「DeepSeek 辅助 → AI 服务设置」填写自己的 Key。默认隐藏输入，本机保存到当前 Windows 用户的凭据管理器；也兼容 DEEPSEEK_API_KEY，保存值优先。清除本机保存值不会清除环境变量。默认模型 deepseek-chat，可由 DEEPSEEK_MODEL 覆盖。

搜索开始后可能进行多轮付费 API 请求，并按界面说明发送未加密文件的名称、路径和属性，不发送正文。AI 归类、摘要另有正文上传确认。加密项目即使本地解锁也不允许上传。同一 Windows 用户下的应用账号共用本机 AI 凭据来源。

## 故障处理

- DLL 缺失：重新完整解压可信发布包，不要从随机网站下载单个 DLL。
- 无法保存：检查目录写权限和磁盘空间；如提示存档损坏，不要清空或重置系统，先保留原始存档备份。
- AI 超时、限流或服务异常：根据提示检查网络、账户余额或模型配置；可取消并继续本地演示，不需要改源码。
- 新版程序未显示：先关闭旧进程，再从此发布目录的启动脚本打开。
